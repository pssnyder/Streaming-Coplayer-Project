# Banter Bot - Test Phrases

## Horror Game Scenarios
- "Ahhhh what was that!!??"
- "Did you hear that noise?"
- "I'm not going in there"
- "Why did I open that door"
- "Nope nope nope turning around"
- "My heart is literally pounding right now"
- "That jump scare got me so bad"

## Exploration/Puzzle Scenarios  
- "I've checked the map but I don't see it"
- "Where am I supposed to go now"
- "This puzzle makes no sense"
- "Been running in circles for 10 minutes"
- "Oh THAT's what I was supposed to do"
- "Finally found it!"
- "This game needs better waypoints"

## Combat/Action Scenarios
- "Run run run run run faster faster faster pleaseee!"
- "That was way too close"
- "How am I still alive"
- "Perfect timing on that dodge"
- "Yeah that's not gonna work"
- "Absolutely destroyed that enemy"
- "I need to heal like right now"

## Success/Failure Moments
- "Well that worked out just fine"
- "Calculated. Totally calculated."
- "I meant to do that"
- "Of course that happened"
- "Are you kidding me right now"
- "YESSSS finally!"
- "I give up on this part"

## General Gaming Commentary
- "This is fine. Everything is fine."
- "What's the worst that could happen"
- "Famous last words right there"
- "Hold on let me try something"
- "That's definitely not supposed to happen"
- "The game is broken, not me"
- "Why is this so hard"


Then WITHOUT trigger (in conversation):
```
What's the worst that could happen
The game is broken, not me

```

## Testing Commentary Mode

Enable commentary mode and try these WITHOUT trigger:
```
Ahhhh what was that!!??
Well that worked out just fine
I give up on this part
```

Gary should interject with sarcastic comments even without being addressed.

## Expected Response Examples

**User:** "Gary, that jump scare got me so bad"  
**Gary:** "Oh yeah, I'm sure that was totally unexpected in the horror game. Who could've seen that coming?"

**User:** "I've been running in circles for 10 minutes" (in conversation)  
**Gary:** "Maybe if you spent less time running and more time looking, you'd find something. Just a thought."

**User:** "Well that worked out just fine"  
**Gary:** "Yeah, 'fine' is one word for it. Lucky is another. Chaotic is probably more accurate."

**User:** "Ahhhh what was that!!??" (commentary mode)  
**Gary:** "That would be the monster you just walked straight toward. But hey, great survival instincts."
